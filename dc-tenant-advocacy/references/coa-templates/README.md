# D.C. tenant cause-of-action and defense templates

Baseline element lists for the `claim-chart` skill. Each file states its elements, the authority each element comes from, and a provenance tag:

- `[CourtListener — retrieved 2026-10-07]` — the authority was pulled and the quoted passage read on that date.
- `[model knowledge — verify]` — not yet checked against the source. Check before filing.

The controlling authority is always the current statute, the Superior Court's standard civil jury instructions for D.C., and DCCA case law — not these files. When a template and the controlling text disagree, the controlling text wins and the template should be corrected.

| File | Claim / defense | Typical posture |
|---|---|---|
| `warranty-of-habitability.md` | Breach of implied warranty of habitability | Defense to nonpayment; counterclaim for abatement |
| `cppa.md` | D.C. Consumer Protection Procedures Act | Counterclaim / affirmative claim |
| `retaliation.md` | Retaliatory action, D.C. Code § 42-3505.02 | Defense to possession; counterclaim |
| `constructive-eviction.md` | Constructive eviction | Counterclaim; defense to rent owed after vacating |
| `defective-notice-and-licensing.md` | Defective notice to quit / unlicensed or unregistered rental | Defense to possession or rent |
